## 📖 Created Mnemonic

**Status:** ✅ Complete

Once upon a time, there was a super tiny computer, a Microcontroller, that controlled things. This tiny computer had a main thinking part, like a brain, called the CPU, and a notepad called memory where it kept its information. The CPU used its notepad to remember things, like a recipe. This recipe, the program, was the set of instructions that told the CPU what to do. The Microcontroller also had little arms called pins that could reach out and give a thumbs up (HIGH) or a thumbs down (LOW) to interact with the outside world. The program, like a recipe written in different languages such as Blockly or C++, told these arms exactly what to do.
